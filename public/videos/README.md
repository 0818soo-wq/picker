# 영상 자산

아래 두 개의 파일을 이 폴더에 넣으면 `/draw` 페이지에서 자동으로 재생됩니다. 파일이 없으면 해당 단계는 자동으로 건너뜁니다.

- `intro.mp4` — 사장님 캐릭터가 "지금부터 추첨을 시작하겠습니다"라고 말하는 인트로 영상
- `win.mp4` — 사장님 캐릭터가 상품을 꺼내며 축하 멘트를 하는 영상 (당첨자 이름은 화면에 텍스트로 별도 표시되므로, 영상 속 멘트는 이름 없이 범용적인 축하 문구로 제작하면 됩니다)

권장 스펙: mp4(H.264), 1280x720 이상, 음성 포함, 각 10초 내외.
